# drop-kicking-babies

![Drop-kicking babies social preview](docs/images/social-preview.png)

Cute babies drop-kicking objects.

Play it: [lewismoten.github.io/drop-kicking-babies](https://lewismoten.github.io/drop-kicking-babies/)

An Angular app (version 2.0.0 of this project) with sound from howler.js.

## Run it locally

```sh
npm install
npm start
```

`npm run build` builds the site for the `/drop-kicking-babies/` path on GitHub Pages.

See the [attribution markdown](attribution.md) for images, audio, and libraries.
